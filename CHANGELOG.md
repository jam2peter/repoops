# Changelog

## v0.1-beta

Initial public beta.

- Issue-comment repository creation for public/private repositories.
- Author-association guard.
- Idempotent repository lookup/create behavior.
- Visibility mismatch refusal.
- Configurable GitHub Project V2 owner/number/repositories.
- Full ProjectV2 item pagination.
- Optional REPOOPS metadata classification.
- Configurable Status/Project/Repository/Operator/date fields.
- Automatic TEXT helper-field creation when enabled.
- Non-destructive installer.
- Synthetic tests and public sanitization CI.
